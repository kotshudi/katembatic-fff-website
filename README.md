# Katembatic FFF Website

Official digital home of **Katembatic FFF — Family, Faith and Finance**.

## Ecosystem

- **OpenPath:** Languages, skills and career-focused education
- **KSF:** Community-powered solidarity finance
- **KSH:** Trusted digital commerce
- **K-AI:** Human-centered technology and intelligence

## Current release

The first release includes a responsive, accessible homepage with the Katembatic identity, ecosystem overview, founding pillars and contact call-to-action.

## Local preview

Open `index.html` in a modern browser or serve the folder with any static web server.
